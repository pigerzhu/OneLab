# OneLab

三星 One UI 功能扩展与折叠屏应用适配模块。

OneLab 是一个面向三星设备的 LSPosed 模块，重点补充系统中无法直接打开、
缺少自定义入口的功能，并改善部分应用在 Galaxy Fold 展开屏、分栏和半折状态下的使用体验。

许多 Android 应用本身已经具备大屏、双栏或折叠屏布局，但这些功能可能受到
机型、系统厂商、地区、屏幕方向或应用内部配置限制。OneLab 会尽可能恢复这些
原生能力，并为三星系统补充更多可自定义的入口。

> OneLab 已结束 Beta 阶段，当前正式版本为 1.0。
>
> 项目主要在 Samsung Galaxy Z Fold6、One UI 8.0 上进行实机验证，
> 同时结合 One UI 8.5 固件进行兼容检查。系统固件或目标应用升级后，
> 部分依赖应用内部实现的功能仍可能需要重新适配。

## 主要功能

### 网络与连接

- 自定义认证页面关闭延迟

### 性能与温控

- Enhanced processing 处理速度
- SIOP 性能限频拦截
- 手动控制 GPU 频率范围，并读取当前设备实际支持的频率点
- 游戏热预算调整
- SDHMS 隐藏温控

### 系统界面

- 记住弹出窗口的位置与大小
- 展开时使用完整外屏
- 按应用设置刷新率策略
- 按应用自定义宽高比
- 应用分栏比例
- 外屏显示内容

### 应用与折叠屏适配

OneLab 目前已针对 17 款应用提供大屏、分栏或半折布局适配，包括携程、QQ、
哔哩哔哩、小红书、Instagram、TikTok、网易云音乐、飞书等等。

- 将部分应用已有的折叠屏声明转换为三星分屏规则
- 改善 QQ、IT之家、虎扑和同程旅行的原生分栏与三星系统开关联动
- 启用哔哩哔哩、百度、小红书和小米商城已有的大屏或折叠屏布局
- 启用 Instagram 和 TikTok 的视频侧边评论区
- 支持 TikTok 竖屏侧栏和直播抽屉避让
- 让三星 Fold 的折叠状态触发网易云音乐内置的半折播放器
- 支持飞书应用内双栏的左右比例调节
- 为微信、京东、酷安等应用提供通用分栏比例支持

QQ、IT之家和虎扑的功能开关由三星系统统一管理：

> 设置 → 高级功能 → 实验室 → 应用程序分屏视图

其中，IT之家自带实验室中的分屏视图开关会与三星系统开关联动。

这些功能并没有从 OneLab 中删除。OneLab 仍会在后台提供折叠屏识别、
分栏规则、状态同步和比例支持，只是将开关交由三星系统统一管理。

应用本身必须具备相应的大屏或分栏代码，OneLab 无法为完全没有大屏布局的应用
凭空创建一套界面。建议优先使用较新的应用版本。

### 实验功能

- 显示 Samsung Gallery Labs
- 可选的 Gallery Labs 简体中文翻译
- 外屏侧边防误触参数

Gallery Labs 翻译不依赖固定图库版本号。图库更新后，名称保持不变的已有项目
通常仍可继续翻译；新增且尚未收录的项目会保留英文，不会影响其他内容。

## 语言支持

OneLab 支持简体中文、繁体中文和 English。Android 13 及以上系统可以通过
“设置 → 应用程序 → OneLab → 语言”单独设置界面语言，也可以从 OneLab 的
外观设置页面打开同一个系统入口。

## 使用要求

- Samsung One UI 设备
- Android 13 或更高版本
- Root
- LSPosed, Xposed API 100

部分功能依赖特定三星服务、硬件能力或目标应用版本，因此不会在所有设备上产生相同效果。

## 安装

1. 下载并安装 APK。[OneLab 1.0 APK](https://github.com/pigerzhu/OneLab/releases/download/v1.0/OneLab-v1.0.apk)
2. 在 LSPosed 中启用 OneLab。
3. 按实际使用的功能配置作用域。
4. 重启对应应用；涉及系统框架或三星系统服务时重启手机。
5. 打开 OneLab 配置需要的功能。

不要同时启用会修改相同设置或 Hook 相同方法的模块。升级前建议保留上一版 APK，便于出现兼容问题时回退。

## 问题反馈

遇到问题时，请在 OneLab 设置中的“诊断与反馈”执行：

1. 点击“开始记录”。
2. 复现问题。
3. 点击“停止记录”。
4. 点击“生成并分享”。

报告会保存到 `下载/OneLab/`。提交 Issue 时请同时提供：

- OneLab 版本
- 手机型号和 One UI 版本
- 目标应用名称及版本
- LSPosed 作用域
- 清晰的复现步骤
- 预期结果与实际结果
- 诊断报告

诊断报告会过滤常见账号与网络敏感字段，但上传前仍建议自行检查内容。

报告还会附带三星分屏列表快照、应用资格与比例配置对照，以及设备运行时状态，便于定位应用未出现在列表中或比例未生效的问题。

## 构建

项目使用 Gradle Wrapper：

```powershell
.\gradlew.bat :app:assembleDebug
```

APK 输出目录：

```text
app/build/outputs/apk/debug/
```

开发规范和目录约定见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

## 注意事项

OneLab 包含实验性系统功能。错误的温控、性能或窗口参数可能造成发热、耗电增加、
应用崩溃或界面异常。请逐项启用并确认效果，出现问题时先关闭对应功能并重启设备。

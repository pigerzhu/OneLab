# 汽水音乐大屏模式开关设计

## 目标

在 OneLab 的“应用”页面增加汽水音乐大屏模式开关，可靠写入目标应用自身的 Pad 识别缓存，并支持关闭时恢复原值。

## 方案

新增应用层设置卡片与 `QishuiMusicClient` 系统客户端。客户端仅在用户明确操作开关后运行 root 命令：停止目标应用、从当前 APK 提取所需库、执行 Keva Dex 读取/写入，并在写入前保存原始记录。写入成功后重新读取确认；关闭操作恢复备份。UI 通过后台执行更新为最后确认状态。

## 边界

- 不修改全局设备属性，不加入 LSPosed 作用域，不注入目标应用。
- 仅支持当前 ABI、仓库、键和记录结构匹配的版本；不匹配时失败并保留原状态。
- 新增文本同步维护简体中文、繁体中文和英文资源。
- 研究产物留在 `analysis`，生产代码不从该目录加载。

## 验收

开关可见；开启前备份、写入和回读验证成功；关闭可恢复原记录；失败时 UI 不显示未确认状态；单元测试和项目要求的 Gradle 验证通过。

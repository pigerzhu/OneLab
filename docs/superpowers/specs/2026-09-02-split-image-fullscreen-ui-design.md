# 分栏图片全屏 UI 设计

## 目标

为“分栏图片全屏”提供一个可复用的入口组件。第一阶段只实现界面与导航骨架，供实机确认视觉和交互；酷安图片查看器的 `alwaysExpand` 行为在后续功能实现中接入。

## 入口卡片

应用页面新增“分栏图片全屏”卡片。卡片保持 OneLab 现有圆角、颜色、内边距和字体规范，并划分为两个独立触控区域：

- 左侧显示标题，点击进入应用管理页；
- 中间显示竖直分隔线；
- 右侧显示总开关，只负责整体启停。

不显示箭头、“管理”文字或副标题。点击左侧不得改变总开关，点击开关不得触发页面导航。

## 通用组件

在 `ui` 包新增可复用组件 `SplitActionSwitchCard`。组件只负责布局、触控区域、颜色和无障碍信息，不读取 Settings，不包含包名或功能设置键。

调用方提供：

- 标题；
- 当前开关状态；
- 左侧点击回调；
- 开关状态变化回调；
- 启用状态和无障碍描述。

组件允许将来增加可选副标题，但本功能入口不使用副标题。

## 管理页

点击左侧进入“分栏图片全屏”管理页。页面复用应用读取器，并显示“设备读取到的已安装应用”与图片全屏适配白名单的交集。第一版白名单只有酷安。

应用读取器新增可选的行尾开关模式。该模式保留图标、名称、搜索、排序和刷新能力，右侧显示 `MaterialSwitch`，不显示状态文字。只有开关本身可以改变状态；点击图标、名称或行背景不执行操作。保存失败时开关恢复原状态。未使用该模式的刷新率、比例等现有页面维持原行为。

总开关关闭时，应用选择保持保存但暂不生效；再次开启后恢复原选择。

第一阶段安装预览版时，只要求完成入口卡片、独立点击区域、管理页和酷安行的视觉与导航，不安装实际酷安全屏规则。

## 状态归属

功能 Screen 持有总开关和应用选择的设置键，并负责导航。通用组件只接收状态与回调，保持依赖方向为：

```text
MainActivity -> feature Screen -> ui component
```

## 本地化与无障碍

新增文字同步更新简体中文、台湾繁体中文、英文和韩文资源。左侧入口和右侧开关分别拥有准确的点击与开关语义，整个卡片不再声明为一个重复的可点击控件。

## 验证

- 单元测试验证总开关关闭时应用选择仍被保留；
- 编译、lint 和资源检查通过；
- 安装到 Android user 0；
- 实机确认左右触控区域互不串联、分隔线位置正确、页面返回正常；
- UI 通过后再设计和实现酷安 `FullScreenActivity` 的精确全屏规则。

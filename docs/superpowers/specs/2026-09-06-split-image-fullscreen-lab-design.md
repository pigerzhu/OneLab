# 分屏图片全屏功能迁移到实验室

## 目标

将现有“分栏图片全屏”入口从“三星应用适配”页面迁移到“实验室”页面，并将显示名称统一改为“分屏下全屏浏览图片”。

## 范围

- 从三星应用适配页面移除现有入口。
- 在实验室页面添加同一个入口，保留现有总开关、可点击卡片和逐应用开关页面。
- 子页面返回目标由三星应用适配页面改为实验室页面。
- 同步更新简体中文、繁体中文、英文和韩文资源名称。
- 保留现有设置键、开关状态、支持应用列表和运行时 hook，不迁移底层实现。

## 验收

- 三星应用适配页面不再显示该入口。
- 实验室页面显示“分屏下全屏浏览图片”。
- 点击入口可进入原有应用列表，返回后回到实验室。
- 已保存的总开关和逐应用开关状态不丢失。
- 单元测试、lint 和 debug 构建通过，APK 安装到 Android user 0。
